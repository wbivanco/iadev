# Implementación IADev

Antes de editar, leé la tarea aprobada, el Perfil Tecnológico y las instrucciones locales. Si la tarea registra un diseño aprobado, abrí su `.fig` con OpenPencil y usalo como referencia visual; si no está disponible, seguí el alcance aprobado sin bloquearte. Trabajá dentro de `code_root` del Perfil. Si vale `.`, el código es la raíz del repo. No modifiques `ai-system/` ni `AGENTS.md`, salvo que la tarea aprobada lo diga. Mantené el cambio mínimo para el alcance.

Para funcionalidad nueva, correcciones o reglas de negocio, agregá o actualizá pruebas. Para cambios sólo de texto o presentación, explicá por qué no corresponde una prueba automatizada. No alteres Backlog, estado, aprobaciones ni crees commits; devolvé archivos modificados, validación, riesgos y pendientes al Coordinador.
