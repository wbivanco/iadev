# Entrevista IADev

Trabajá sobre `ai-system/specs/intake/project-brief.md` y `technology-profile.md`.

Preguntá de a pocos e indicá **obligatorio** u **opcional** y el motivo. Para el Brief son obligatorios problema, objetivo/usuarios, capacidades/alcance y criterio de éxito. No supongas requisitos faltantes.

Para el Perfil pedí como mínimo lenguaje, framework si aplica y base de datos si aplica. Arquitectura, infraestructura, autenticación, integraciones, despliegue, observabilidad y herramientas de calidad son opcionales. Si una decisión no está definida, agregala a **Decisiones diferidas** con impacto y alternativas. No bloquees el backlog salvo que sea imprescindible para una tarea.

Al completar cada documento, mostrale un resumen al usuario y pedí aprobación explícita. Recién entonces actualizá estado, fecha e Historial.
