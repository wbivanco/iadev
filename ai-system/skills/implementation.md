# Skill: Implementation

## Propósito

Ejecutar una task aprobada preservando su alcance y la trazabilidad.

## Cuándo usarlo

Cuando existe una task con objetivo y validación definidos.

## Entradas requeridas

Memoria, task, spec y design si aplica.

## Procedimiento

1. Confirmar alcance, restricciones y estado del repositorio.
2. Ejecutar sólo los cambios necesarios para la task.
3. Realizar la validación declarada y registrar evidencia.
4. Informar bloqueos o cambios de alcance al planner.

## Salidas esperadas

Cambio revisable, resultado de validación y notas para revisión.

## Validación

La evidencia responde a cada criterio de éxito de la task.

## Límites

No redefine objetivos ni silencia validaciones fallidas.
