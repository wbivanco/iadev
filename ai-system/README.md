# IADev

IADev es un kit portable de coordinación de desarrollo con Codex. El código vive en `workspace/`; la memoria, definición de producto y backlog viven en `ai-system/`. No requiere runtime, servidor ni base de datos: los documentos Markdown versionados son la fuente de verdad.

Leé [la guía de adopción](docs/adoption-guide.md) para iniciar o retomar un proyecto.
