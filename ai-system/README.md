# AI Development System v1.0.0

Kit portable para planificar, ejecutar y cerrar trabajo asistido por IA sin depender de una herramienta, lenguaje o producto específico.

Incluye memoria persistente, desarrollo guiado por especificaciones, templates, skills reutilizables, roles de agentes y una validación manual de portabilidad.

## Empezar

Leé [la guía de adopción](docs/adoption-guide.md), personalizá `memory/` para el proyecto destino y ejecutá la [checklist de portabilidad](docs/portability-checklist.md).

El código real del proyecto vive por convención en `../workspace`; esta ruta puede adaptarse durante la inicialización.

## Alcance de v1

La v1 define un proceso manual y trazable. No incluye automatización de agentes, integraciones de IDE/MCP, búsqueda avanzada ni orquestación autónoma; son posibles evoluciones posteriores.
