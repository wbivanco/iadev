# IADev

IADev es un kit portable de coordinación. El motor se instala una vez por máquina. La memoria de cada producto vive en su `ai-system/`. No requiere runtime, servidor ni base de datos: los documentos Markdown versionados son la fuente de verdad.

La instalación y el `init` de cada producto están en el [README de la raíz](../README.md). El ciclo de trabajo está en [la guía de adopción](docs/adoption-guide.md).
