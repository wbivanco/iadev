# MEMORY.md

## Cómo usar esta memoria

Antes de trabajar en el proyecto:

1. Leer `current-state.md`
2. Revisar `project-summary.md`
3. Buscar decisiones relevantes en `decisions.md`
4. Revisar dudas abiertas en `open-questions.md`

## Estructura

- `project-summary.md`: visión general del sistema
- `current-state.md`: estado actual del proyecto
- `decisions.md`: decisiones técnicas y de negocio
- `open-questions.md`: dudas pendientes
- `session-log.md`: historial de sesiones
- `agent-handoffs.md`: traspasos entre agentes

## Regla clave

Esta carpeta es la fuente de verdad del contexto del proyecto.
No confiar únicamente en el contexto del chat o del agente.
