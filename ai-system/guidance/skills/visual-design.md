# Skill: Visual Design

## Propósito

Crear un diseño visual aprobable para una task UI mediante el MCP OpenPencil.

## Procedimiento

1. Leer la task, spec, design y memoria aplicables.
2. Usar exclusivamente el MCP `open-pencil`.
3. Guardar el resultado en `workspace/design/<task-id>.fig`.
4. Informar evidencia, riesgos y la ruta del artefacto.
5. Esperar la aprobación humana antes de implementar.

## Límites

No modificar código de producto ni sustituir el diseño visual por Markdown.
