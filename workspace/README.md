# Workspace

Aquí vive el código real del proyecto.

Antes de modificar esta carpeta, los agentes deben revisar `../ai-system`.

Este directorio comparte el repositorio Git raíz. La integración local creada
por `aidev setup codex` en `.agents/` se ignora y puede regenerarse. Cada
proyecto debe agregar un `.gitignore` propio para las dependencias, builds y
archivos temporales de su stack; no ignorar código fuente ni tests.
