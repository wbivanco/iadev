# Workspace

Aquí vive el código real del proyecto. Abrí Codex desde la raíz del repositorio para que cargue `AGENTS.md`, los skills y los agentes de IADev.

Antes de modificar esta carpeta, el implementador debe leer el Perfil Tecnológico y la tarea aprobada. Las reglas específicas del código viven en `workspace/AGENTS.md`; el contexto, backlog y memoria permanecen en `../ai-system/`.

Este directorio comparte el repositorio Git raíz. Agregá aquí los `.gitignore` necesarios para dependencias, builds y archivos temporales del stack; no ignores código fuente ni tests.
